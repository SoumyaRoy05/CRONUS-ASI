# CRONUS-ASI Tools & Utilities

This directory contains standalone diagnostic, testing, and maintenance utilities for CRONUS-ASI.

## Available Tools

- **`Mic_Check.py`**: Live microphone input test and RMS audio amplitude visualizer. Run this tool to verify audio input hardware and sampling rates before engaging CRONUS speech recognition.

### Usage
```powershell
.venv\Scripts\python.exe tools\Mic_Check.py
```
